# ATLAS 3.2 — Fresh Repository

## النشر
1. أنشئ مستودع GitHub جديدًا.
2. ارفع `index.html` و`README.md` و`.nojekyll` إلى جذر المستودع.
3. من Settings → Pages اختر Deploy from a branch ثم `main` و`/(root)`.

## إصلاح Gemini
- تم تصحيح اسم النموذج الافتراضي إلى `gemini-2.5-flash` بدل اسم النموذج غير الصحيح المستخدم في النسخة السابقة.
- أدخل مفتاحًا صالحًا من Google AI Studio ثم اضغط حفظ واختبار الاتصال.
- إذا فشل الاتصال، اقرأ رسالة الحالة التفصيلية؛ قد يكون السبب مفتاحًا غير صالح أو قيودًا على المفتاح أو الحصة أو اتصال الشبكة.
- لا تشارك مفتاح API مع أحد.

## الواجهة
- تأثير Liquid/Jelly Glass منفصل بصريًا عن الخلفية المتحركة على الأزرار والبطاقات والأيقونات وحقول الإدخال.
- الأيقونات لها سطح زجاجي مستقل ولمعة وحركة عائمة خفيفة.
- طبقة الخلفية المتحركة خلف محتوى الموقع.

## حدود مهمة
- رفع PDF حتى 500 MiB هو حد واجهة فقط؛ Google قد تفرض حدودًا أقل على حجم الملف أو عدد الصفحات أو مدة المعالجة.
- مفتاح API محفوظ محليًا في المتصفح، وقفل الإعدادات ليس حماية للمفتاح. لموقع عام استخدم Backend/Worker.
- بيانات الطالب محفوظة محليًا ولا توجد مزامنة سحابية.
